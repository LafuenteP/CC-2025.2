Criptografia: Meio para transformar um texto simples como forma de
transmiti-lo aos seus destinatários com segurança.
- O legível se torna ilegível.
- Principal método para proteger informações valiosas.

Usa algoritmos matemáticos para transformar dados em um formato que não seja prontamente decifrável.

E necessário de um algoritmo zero e de uma ou mais chaves de decriptar 

### Conceitos - 

- Plaintext (Texto claro): Texto original, antes de passr por um processo de criptografia.
- Cipher Text (Texto cifrado): Texto depois de passar pelo algoritmo de criptografia, cifrando ele.
- Decifragem: Restaurar o texto claro a partir do texto cifrado e uma chave
- Sistema Criptográfico ou Cifra: Esquema utilizado para a realização criptográfica.
- Criptoanálise: Técnicas utilizadas para decifrar uma mensagem sem conhecer os detalhes da criptografia.
- Criptologia: Consiste nas áreas da criptografia e criptoanálise juntos.

### Elementos -

- Texto claro
- Chave da origem
- Algoritmo de criptografia
- Texto cifrado
- Chave do destino
- Algoritmo de decriptografia 

### Uso das chaves - 
São usadas como entrada na hora de criptografar e decifrar 
- O algoritmo pode ser conhecido por todos.
- Porém as chaves precisam ser secretas.
Os ataques podem ser:
- Criptoanálise: utiliza conhecimentos do algoritmo ou amostras do texto claro/cifrado
- Força bruta: tenta todos os valores possíveis de chave

### Dimensões de uma criptografia 
- Modo como o texto claro é processado
	Cifra de bloco
	Cifra de fluxo
- Tipo de operações utilizadas para transformar o texto claro em texto cifrado
	Cifras de Substituição
	Cifras de transposição
	Sistemas de Produto
- Número de chaves utilizadas
	Criptografia Simétrica
	Criptografia Assimétrica
